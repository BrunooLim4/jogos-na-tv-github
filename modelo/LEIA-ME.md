# Modelo de jogo

Esta pasta é o **ponto de partida de todo jogo novo**: a sala com QR code, o
líder, o "pronto", a reconexão e os testes já funcionam, num visual simples e
neutro (o "estilo padrão").

Para começar um jogo novo: copie esta pasta para `jogos\<nome-do-jogo>`, faça o
jogo funcionar neste estilo simples e, depois, dê a personalidade dele (cores,
fontes, personagens, sons). Nada é copiado de outro jogo: cada um tem a sua cara.

Para ver como fica: dois cliques em `iniciar.bat` e leia o QR com o celular
(precisa de 2 pessoas para começar; a partida aqui é só um quadro vazio).
